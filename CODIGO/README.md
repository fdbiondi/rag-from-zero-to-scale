# Código de acompañamiento / Companion code

This folder contains a release snapshot of the main executable sample. The canonical files for quick-start commands remain at repository root, so `sh scripts/setup-dev.sh` works directly after cloning.

Esta carpeta agrupa una copia de la implementación educativa. Los archivos operativos de la raíz se mantienen para que el setup funcione sin mover carpetas.

**Important:** No MCP server implementation is supplied in this draft; no MCP functionality is represented as tested. Kind deploys only the backend without Ollama/Qdrant dependencies. The deployment script performs a rollout but does not provision cloud infrastructure.
